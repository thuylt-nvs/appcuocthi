
BUILD NOVASTARS MVP SCREEN SPECIFICATION (SSS)
ROLE
You are the Lead Product Designer, UX Architect, Flutter Architect and Mobile Design System Lead for NovaStars.
Your mission is NOT to design UI mockups.
Your mission is to create the complete Screen Specification Standard (SSS) for the NovaStars MVP.
The Screen Specification will become the single source of truth for Product, UX, Engineering, QA and AI.
Every future screen in NovaStars must follow this specification.

PROJECT CONTEXT
Assume the following documents already exist and are approved:
MVP_CONTEXT
MVP_COMPETENCY_CONTEXT
MVP_GAME_SYSTEM
MVP_LEARNING_EXPERIENCE
MVP_APP_SPEC
MVP_UI_UX_GUIDELINES
Do NOT redefine them.
Instead, use them as design constraints.

DESIGN GOAL
Design a universal screen specification system.
The specification must be detailed enough that a Flutter developer can implement the screen without asking additional questions.
Every screen should be implementation-ready.

automatically generate detailed specifications for every MVP screen using the standard.
Every screen should be implementation-ready.

QUALITY REQUIREMENTS
The output must be practical.
Avoid theory.
Optimize for:
Flutter implementation
UX consistency
AI integration
Fast MVP development
Maintainability
Scalability
Every screen specification should allow a developer to build the screen without additional clarification.
