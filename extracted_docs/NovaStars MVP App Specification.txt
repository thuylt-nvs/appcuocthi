
NovaStars MVP App Specification (MVP_APP_SPEC)
Product Goal
Build the first playable version of NovaStars.
The objective is to validate that primary school students enjoy learning life skills through a Duolingo-inspired adventure game.
This is an MVP.
The application should optimize for:
Fast learning
High engagement
Daily return
Simple implementation
Not scalability.

MVP Scope
The MVP contains only one complete learning world.
Example:
World 1
↓
5 Islands
↓

↓

Total:
25 Competencies

Stars

Daily Quest
Three quests generated daily.
Examples
Complete one lesson.
Complete one Boss.
Finish one challenge.
Daily Quest grants bonus XP.

Boss Rules
One Boss per competency.
Boss validates competency mastery.
Replay allowed.
Must pass to complete lesson.

Reflection Rules
One reflection per lesson.
Reflection is mandatory.
Short.
Inside app only.

Challenge Rules
One real-life challenge.
One-day completion.
Parent verification required.

Confirms challenge completion.
No grading.

Success Metrics
The MVP succeeds when:
A child completes one competency independently.
A child returns the next day.
A child completes an island.
Parents understand the value.
The learning journey feels like a game.

Non-Goals
Do NOT build:
AI Content Factory
CMS
Teacher Portal
Marketplace
Multiplayer
Localization
Advanced Analytics
Advanced Pet Skills
Live Events
Community Features

Definition of Done
The MVP is complete when a child can:
Log in.
Select an island.
Choose a competency.
Complete the full learning journey.
Receive rewards.
Unlock new progress.
Exit with progress saved.
Return the next day and continue playing.
If these eight actions work smoothly, the MVP has achieved its purpose.
