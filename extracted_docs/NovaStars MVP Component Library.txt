
NovaStars MVP Component Library (MVP_COMPONENT_LIBRARY)
Purpose
This document defines every reusable UI component used in the NovaStars MVP.
The component library ensures:
UI consistency
Fast development
Reusable Flutter widgets
Better UX
Consistent gamification
Easier maintenance
Every screen must be built by assembling these components.

Design Principles
Every component must be:
Child-friendly
Touch-friendly
Emotionally engaging
Simple
Reusable
Accessible
Consistent
Animation-ready
Children should recognize patterns immediately.

The component library is divided into seven groups:

Naming Convention
Every component follows:
NS + Category + Component
Examples:
NSPrimaryButton
NSCompetencyCard
NSStoryBubble
NSRewardPopup
NSBossArena
NSIslandCard
NSProgressBar

Flutter Mapping
Every component should map directly to one reusable Flutter Widget.
Example:
NSPrimaryButton
↓
PrimaryButton.dart
NSCompetencyCard
↓
CompetencyCard.dart
NSRewardPopup
↓
RewardPopup.dart
Reusable widgets should never duplicate logic.
