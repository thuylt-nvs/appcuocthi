# MVP_NON_GOALS

## Do NOT build in MVP

- AI Production System
- AI Orchestrator
- CMS
- Marketplace / Shop economy (advanced)
- Multiplayer
- Localization
- Teacher Portal
- Advanced Parent Dashboard
- Advanced Analytics
- Content Factory
- Multi-country support
- Complex Pet Skills
- Live Events

## Guiding Principle

Whenever a feature does not directly help validate the core learning experience, postpone it to a future version.
