# NovaStars MVP — Phiêu Lưu Học Kỹ Năng Sống

NovaStars là nền tảng học tập kỹ năng sống cho học sinh tiểu học (6–11 tuổi), lấy cảm hứng từ game phiêu lưu Duolingo.

## 🚀 Milestone 1 — Trải Nghiệm Bài Học Đầu Tiên (First Playable Lesson)

### Tính năng đã hoàn thành:
- **FTUE Onboarding (< 90s):** Lời chào từ nhân vật Sao Nova, hướng dẫn Trang Chủ & Bản Đồ.
- **Bài Học Mẫu Chuẩn (Gold Standard Lesson Zero):** Chủ đề *Lời Chào Ngôi Sao* với 10 giai đoạn học tập hoàn chỉnh (`Pre-test` → `Story` → `3 Mini Games` → `Boss Battle` → `Reflection` → `Real-life Challenge` → `Parent Confirmation` → `Post-test & Rewards`).
- **Kho Widget (12 Components):** UI component phong cách glassmorphism, responsive mobile-first.
- **Âm thanh & Hiệu ứng Synthesizer:** Phản hồi âm thanh Web Audio API không độ trễ và hiệu ứng nổ pháo hoa Confetti Canvas.
